# Business Operations & KPI Analytics

A business analytics project focused on turning operational data into measurable KPIs, identifying performance trends, investigating anomalies, and producing business recommendations.

## Objective

Analyze operational performance across products, regions, and time periods using SQL and Microsoft Excel.

## Tools

- SQL
- PostgreSQL
- Microsoft Excel

## Analysis Areas

- Revenue and order performance
- Regional performance
- Product performance
- Monthly trends
- KPI comparison
- Data quality checks
- Anomaly identification
- Business recommendations

## Workflow

1. Load structured operational data.
2. Validate and clean the dataset.
3. Use SQL to filter, join, group, and aggregate records.
4. Calculate business KPIs.
5. Compare performance across periods and categories.
6. Investigate unusual changes.
7. Prepare Excel-based reporting and recommendations.

## Project Status

In progress. The repository is intended as a practical Business Analyst portfolio project and will be expanded with SQL analysis, reporting files, and documented findings.
